# Student-Performance-Analysis
Student performance analysis using Python and Pandas.


## Project Overview
The Student Performance Analysis project is developed using Python and Pandas to analyze student academic performance. It processes student data, calculates total marks and average marks, assigns grades, and identifies whether students have passed or failed based on their performance and attendance.

## Objectives
- To analyze student academic performance.
- To calculate total and average marks.
- To assign grades based on average marks.
- To check student results using marks and attendance.
- To organize student data using Python and CSV files.

## Technologies Used
- **Python** – Programming language
- **Jupyter Notebook** – Development environment
- **Pandas** – Data analysis and data manipulation
- **NumPy** – Numerical operations
- **CSV** – Dataset storage

## Dataset Description
The dataset contains student information with the following columns:

- Student ID
- Name
- Department
- Python Marks
- DBMS Marks
- Computer Networks Marks
- Mathematics Marks
- Attendance

## Project Features
1. Reads student records from a CSV file.
2. Calculates total marks and average marks.
3. Assigns grades according to average marks.
4. Determines Pass or Fail based on average marks and attendance.
5. Displays the analyzed student records.

## Installation and Setup

1. Install Python on your computer.
2. Install Jupyter Notebook.
3. Install the required libraries:

```bash
pip install pandas numpy notebook
```

4. Keep `student.csv` and `student_analysis.ipynb` in the same folder.
5. Open Command Prompt in the project folder and run:

```bash
jupyter notebook
```

6. Open the notebook and run the cells step by step.

## Expected Output
The project displays student records along with calculated total marks, average marks, grades, and final results.

This project demonstrates how Python can be used to analyze student performance efficiently. It helps organize academic records and calculate grades and results automatically.
